# Seravine - Luxury Fragrances

Seravine is a premium e-commerce platform for high-end fragrances, built with a focus on luxury aesthetic, smooth animations, and a seamless shopping experience.

## Features

- **Luxury Design**: A meticulously crafted UI with a sophisticated color palette and typography.
- **Smooth Animations**: Integrated GSAP for fluid entrance effects and interactive transitions.
- **Interactive Shop**: Advanced filtering by collection (Men, Women, Unisex) and dynamic sorting.
- **Persistent Cart**: A fully functional cart system with state persistence via localStorage.
- **Optimized Performance**: Built with Next.js and React 19 for industry-leading speed and SEO.

## Technology Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Animations**: GSAP (GreenSock Animation Platform)
- **Styling**: Tailwind CSS & Lucide Icons
- **State**: React Context API & Storage API

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the results.

## Production Build

To build the project for production:

```bash
npm run build
```

The optimized static pages will be generated in the `.next` directory.
